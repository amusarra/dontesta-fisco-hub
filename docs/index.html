Strumento di consultazione

Dal file XML scaricato da AdE a una visione chiara dei tuoi dati.

FiscoHub è pensato per piccole attività e professionisti che vogliono consultare autonomamente le proprie fatture e corrispettivi senza dover sempre rivolgersi al commercialista o usare gestionali complessi. Combina visualizzazione, ricerca ed elementi di analisi in un'interfaccia semplice e immediata.

⌘

Importazione intelligente

Carica i file XML scaricati dal Portale Fatture e Corrispettivi dell'Agenzia delle Entrate. Trascinali nell'app o, nella versione desktop, seleziona una cartella. FiscoHub riconosce automaticamente fatture e corrispettivi.

⌑

Fatture XML e P7M

Legge FPA12 e FPR12, compresi i file .xml.p7m firmati CAdES. Il payload XML viene estratto localmente, senza plugin esterni.

▤

Corrispettivi telematici

Importa XML COR10, inclusi i periodi inattivi. Consulta riepiloghi, pagamenti, dati del dispositivo e filtra per stato o tipologia.

⌂

Multi-azienda

Crea e gestisci più anagrafiche. Per ogni azienda attiva, FiscoHub classifica le fatture come emesse, ricevute o non classificate usando P. IVA e codice fiscale.

⌕

Ricerca e filtri

Riduci l'elenco per anno, mese, cedente, cessionario, tipo documento e dati identificativi. L'analisi di beni e servizi include anche la ricerca tollerante agli errori di digitazione.

⇩

Export e documenti

Esporta elenchi e dati analitici in CSV. Scarica l'XML, genera un PDF, stampa la fattura, salva l'anteprima HTML e consulta o scarica gli allegati.

Flusso semplice per la consultazione

Dal Portale AdE alla tua analisi, in quattro passaggi.

Scarica i tuoi documenti dal Portale Fatture e Corrispettivi, importali in FiscoHub e consulta i dati. Ogni fase avviene localmente — non c'è un servizio remoto che riceve i tuoi documenti.

Scarica da AdE

Accedi al Portale dell'Agenzia delle Entrate e scarica i file XML delle tue fatture elettroniche e corrispettivi telematici.

Importa

Trascina i file in FiscoHub, selezionali dal dispositivo o imposta una cartella da monitorare nell'app desktop.

Visualizza

I documenti vengono riconosciuti e organizzati automaticamente. Seleziona l'azienda e applica i filtri per isolare ciò che ti serve.

Analizza ed esporta

Consulta i dettagli, confronta ricavi e spese, esplora le statistiche e porta i risultati in CSV, XML, PDF o stampa.

Consultazione veloce

Visualizza ricavi e spese, senza confonderli.

La dashboard distingue ciò che hai emesso da ciò che hai ricevuto, per darti una vista chiara dei tuoi dati fiscali. Nota: questo NON sostituisce il commercialista o la contabilità ufficiale.

01

KPI a colpo d'occhio

Volume d'affari, imponibile e IVA calcolati sulle fatture emesse; conteggi e totali mantengono separati emesse e ricevute per una lettura immediata.

02

Grafici e CSV

Andamento del fatturato, clienti, fornitori, tipi documento e metodi di pagamento. I dati filtrati e i grafici sono esportabili per le tue analisi.

03

Analisi degli acquisti

La sezione Beni e Servizi ricevuti aggrega le righe delle fatture ricevute, per fornitore e descrizione, aiutandoti a capire su cosa stai spendendo.

Privacy by design

I tuoi documenti fiscali non lasciano il tuo dispositivo.

FiscoHub è progettato per lavorare 100% localmente: i file XML importati dal Portale AdE, gli originali, i metadati delle firme e le tue preferenze rimangono nel browser o nell'app desktop, in IndexedDB. Nessun dato viene mai inviato a server esterni.

Nessun account, nessun caricamento a server esterni o cloud.
I file P7M sono decodificati sul posto, inclusi i metadati X.509 della firma digitale.
Puoi sempre eliminare fatture, corrispettivi o l'intero database locale in qualsiasi momento.

Per tecnici

Architettura locale, senza backend applicativo.

FiscoHub è una single-page application TypeScript che interpreta documenti fiscali nel client e conserva dati grezzi e indici derivati sul dispositivo dell'utente.

Flusso dell'applicazione
Documenti in ingressoFatturaPA XML · XML firmato CAdES/P7M · Corrispettivi COR10
Interfaccia e statoReact 19 + TypeScript · componenti, filtri, viste e dashboard
Parsing e dominioDOMParser, validazione strutturale, normalizzazione, lettura PKCS#7/CMS con node-forge
Persistenza localeIndexedDB tramite idb · XML originali, anagrafiche, corrispettivi e indice delle righe documento
DistribuzioneVite per il web statico · Tauri v2 e Rust per l'app nativa multi-piattaforma
Presentazione

React + TypeScript

La UI è organizzata in componenti per elenco, visualizzatore, dashboard, filtri e gestione aziende. TypeScript mantiene espliciti i modelli di fattura, corrispettivo, firma e persistenza.

Elaborazione

Parser separati per ogni formato

Le fatture e i corrispettivi hanno parser dedicati. Per i P7M, il contenuto CMS è elaborato localmente e i dettagli del certificato X.509 vengono resi disponibili insieme al documento.

Dati

Originale più indice derivato

Il database conserva XML e P7M originali per ricaricare fedelmente i documenti; estrae anche le righe delle fatture ricevute in uno store dedicato, rendendo rapide ricerca, aggregazioni e Top Beni e Servizi.

Client-side first

Riduce l'esposizione di documenti fiscalmente sensibili e elimina la dipendenza operativa da un server applicativo.

IndexedDB invece di LocalStorage

È adatto a dati strutturati e file più grandi, con store distinti e accesso indicizzato alle righe documento.

Web e desktop dalla stessa UI

Vite distribuisce una build statica; Tauri racchiude lo stesso frontend in un runtime nativo leggero, con accesso controllato a file e dialoghi.

Difese sul confine dei dati

I file vengono controllati prima del parsing; nomi, URL e contenuti destinati a preview o download sono sanitizzati prima dell'uso.
