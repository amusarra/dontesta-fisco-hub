Tutto il necessario per gestire le tue Fatture Elettroniche

Un'interfaccia raffinata abbinata a un potente motore di parsing client-side, senza inviare dati sensibili a server remoti.

📄

Supporto XML e P7M

Consente di caricare direttamente sia i file standard XML (FatturaPA) sia i file firmati digitalmente in formato CAdES (.xml.p7m).

🔑

Estrazione Firma Digitale Reale

Tramite la libreria open-source node-forge, decodifica il payload PKCS#7 del file .p7m ed estrae i metadati reali del certificato X.509: firmatario (CN), ente emittente, numero seriale, validità, Key Usage, CRL, OCSP e SAN.

💻

Desktop nativo (Tauri v2)

Grazie all'integrazione con Tauri v2, l'app è compilata nativamente come eseguibile desktop leggero e sicuro per Windows, macOS (Apple Silicon e Intel) e Linux.

📊

Filtri Temporali e Ricerca

Organizza e filtra le tue fatture per anno, mese o tramite ricerca testuale su fornitore (Cedente) e cliente (Cessionario).

🔒

Sicurezza Totale (Zero Server)

Il parsing dei file XML avviene interamente all'interno della sandbox del tuo browser o dell'app desktop. I byte del file `.p7m` non lascono mai il dispositivo, e i metadati della firma sono estratti localmente tramite node-forge.

⚙️

Automazione CI/CD (4 piattaforme)

Le build desktop vengono generate automaticamente ad ogni rilascio tramite GitHub Actions su quattro runner in parallelo: macOS Apple Silicon, macOS Intel, Windows e Linux.

Come funziona l'applicazione

Tre semplici passaggi per visualizzare le tue fatture con dettagli professionali.

01

1 Caricamento File

Se il file è firmato digitalmente (`.p7m`), l'app estrae automaticamente l'XML interno tramite la libreria node-forge (PKCS#7/CMS), senza nessun plugin esterno.

02

2 Parsing & Estrazione

Vengono analizzate tutte le sezioni ministeriali della fattura (Cedente/Prestatore, Cessionario/Committente, Dettaglio Linee, Aliquote IVA, Dati di Pagamento, Allegati) e i metadati del certificato di firma digitale X.509.

03

3 Visualizzazione & Download

L'interfaccia visualizza un foglio di stile simile al modello ministeriale ufficiale. Consente di scaricare l'XML pulito o di stampare direttamente la fattura.

Build & Release Automatiche

Il software utilizza le GitHub Actions integrate per compilare i sorgenti in Rust e TypeScript su vere macchine virtuali macOS (Apple Silicon e Intel), Windows e Linux, assicurando la massima compatibilità binaria.

Comando di Build Locale: npm run tauri build

La Pipeline CI/CD di Rilascio

Quattro piattaforme, un solo push: build parallele su macOS Apple Silicon, macOS Intel, Windows e Linux.

Tracciamento delle Release

Ogni release viene tracciata semanticamente e registrata nel file CHANGELOG.md. La pipeline automatica si attiva inserendo un tag git (es. v1.0.0), innescando la compilazione parallela su quattro macchine cloud: macOS Apple Silicon, macOS Intel, Windows e Linux.

Standardizzazione di Rilascio I binari compilati contengono certificati crittografici deterministici e vengono firmati per garantire che l'utente stia eseguendo codice non manomesso e ufficiale del progetto.
# Pipeline Github Actions Workflow (.github/workflows/release.yml)
on:
push:
tags:
- 'v*'
# Compila su macchine reali in cloud
jobs:
build-and-release:
runs-on: [macos-latest (arm64), macos-latest (x86_64), ubuntu-22.04, windows-latest]
steps:
- uses: actions/checkout@v4
- uses: tauri-apps/tauri-action@v1
